# Spice Tree - Pure Veg Punjabi Restaurant Web App

Official modern web application for **Spice Tree**, Phagwara's premier pure-vegetarian multi-cuisine dining and delivery restaurant.

- **Live URL:** https://spicetree-restaurant.web.app
- **Firebase Project:** `spicetree-restaurant`
- **Tech Stack:** React 19 + TypeScript + Vite + Tailwind CSS + Firebase Auth & Cloud Firestore

## 🚀 Run Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```

## 🌐 Deploy to Firebase Hosting

To deploy your latest build live to `spicetree-restaurant.web.app`:
```bash
npx firebase-tools deploy
```
